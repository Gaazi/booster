# Focused review of the new host integration and worker changes

Reviewed checkpoint: `447693df1cb87b45280eb8f67becda0a497c6fb0`.
Scope: new work after `8655226`, plus release-helper compatibility with the
current shared authorization protocol. This is not a full-project review.

## Reproduced defects and fixes

| Priority | Trigger and impact | Fix |
| --- | --- | --- |
| P1 | A peer clear followed by completion of an older Node GET could refill RAM with stale bytes. | Advance the capture generation when applying every peer notice. |
| P1 | A notice file could rotate and refill past a slow reader's cursor, hiding invalidations. Concurrent readers/writers were unsynchronized. | Use a generation header, JSON records and the same bounded local lock in Python and Node. Rotation forces a full clear regardless of cursor size. |
| P1 | A scaffolded Python adapter ignored `invalidation_file`, leaving a configured multi-worker host process-local. | Build the bus once in `SiteConfig.attach_options()` for every consumer. |
| P1 | String `false` enabled Python surgical invalidation/transformations. Invalid settings could silently disable a Node bus; nonfinite/fractional budgets were accepted. | Reject malformed booleans, paths and numeric limits before attaching. |
| P2 | Explicit `LocalInvalidationBus` returned `None` and crashed on the first request. | Return the protocol's empty notice list. |
| P2 | Malformed upstream Age could enter RAM; ASGI hits emitted duplicate Age and Django hits failed to advance it. | Fail closed on invalid Age and share monotonic Age calculation across Python adapters. |
| P2 | `booster-node measure URL` without `--requests` fetched zero samples but exited successfully; its verdict disagreed with runtime privacy guards. | Parse defaults explicitly, validate counts, bound request time, handle failures and reuse runtime admission policy. Test the actual source and installed CLI. |
| P2 | Quoted route prefixes broke generated Python adapter source. | Encode route strings as data literals. |
| P2 | The promotion wrapper did not pass the newly mandatory authorization note or accept annotated merge commits. | Forward the user's instruction, push immediately and compare the tested tree/ancestry rather than assuming an unchanged commit SHA. |

## Evidence

- New regressions failed before their corresponding fixes, including both Node
  invalidation cases and the real CLI default-sample command.
- Local release gate: Python **261 passed**, Node **57 passed**. Python includes
  two real worker processes and concurrent Python/Node journal publishers.
- TypeScript compilation/public declaration checks, changed-file Python syntax
  and audit, pip compatibility check and npm audit passed (no npm findings).
- Versions: Python `1.0.4.dev1`, Node `1.0.1`; installed-package CI remains the
  gate before the explicitly authorized dev/demo/main promotions.

## Limits

No physical-phone, public-network, production, network-filesystem or container
restart validation is claimed. A crashed directory-lock owner needs explicit
operator recovery; the bus fails closed and does not silently ignore errors.
Mixed journal versions must not run together. Existing nonfatal module-detection
and Starlette deprecation warnings remain. Branch promotion does not deploy or
restart a live website.
